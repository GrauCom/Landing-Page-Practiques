Esta es la Landing Page que he hecho, contiene cuatro páginas HTML, index, About, News i Contact, CSS con adaptación a móvil (por debajo de 768px), y el archivo JavaScript.
Una carpeta de imágenes también que contiene todas las fotos usadas en las páginas.
He intentado recrear el estilo que se nos ha dado a través del CSS de la forma más fiel posible, con tamaños y colores fieles al estilo original.
Para el tema del DOM y algunas cuestiones más avanzadas del css me he ayudado de Google, más que nada por el hecho de que tengo muy poca experiencia haciendo funcionalidades con JavaScript y manipulando el DOM. He tenido que buscar en tutoriales y foros abiertos como por ejemplo StackOverflow para poder realizar el trabajo.
Las funcionalidades que he hecho son:
- Scroll suave para redirigirte a secciones de la página.
- Sticky Header que te sigue y se mantiene enganchado en la parte superior de la pantalla según haces scroll.
- Hamburguer, solo para móviles, que muestra y esconde el menú de navegación.
- Formulario con validación de inputs.

Todo este proyecto lo he desarrollado con el IDE PHPStorm, en local. En general JetBrains es un grupo de herramientas fácil de usar, cómodo y versátil.
Para poder ejecutarlo, cualquier IDE capaz de trabajar con HTML y CSS puede abrir el proyecto sin problemas.
